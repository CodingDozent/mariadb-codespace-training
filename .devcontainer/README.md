# MariaDB Codespace Training – Bootstrap

Dieses Repository ist vorbereitet für eine Docker-fähige GitHub Codespaces Umgebung.

**Wichtig:**  
Die Datei `setup.sh` ist aktuell nur ein Platzhalter.  
Nach dem ersten erfolgreichen Codespace-Start wird sie durch die echte Version ersetzt, die MariaDB + phpMyAdmin Container startet.
